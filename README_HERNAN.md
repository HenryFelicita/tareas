# Tareas

API REST de tareas con Spring Boot, Spring Data JPA y PostgreSQL.

## Puesta en marcha

1. Crear la base de datos `tareas` y ejecutar el script `sql/01-crear-tarea.sql`.
2. Definir la variable de entorno `POSTGRES_PASSWORD` con la contraseña del usuario `postgres`.
3. Arrancar `Aplicacion` y abrir `http://localhost:8080/api/tareas`.
